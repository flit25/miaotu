# 喵图

喵图是一款原生 macOS 图片与视频查看器。打开图片后，图片本身就是窗口；鼠标移到窗口上部时显示操作按钮，移到右侧时显示可调整位置的文件信息。支持在同一文件夹中连续浏览、缩略图网格、缩放与平移。

## 下载与安装

从 [最新版本](https://github.com/flit25/miaotu/releases/latest) 下载 DMG，打开后将“喵图.app”拖进“应用程序”文件夹，再从那里启动。不要直接在 DMG 中运行，应用内更新需要可写的安装位置。

目前应用采用临时签名，**没有 Apple Developer ID 签名或公证**。首次打开时 macOS 可能提示无法验证开发者，需要用户在系统设置中手动允许；这不等同于已获得 Apple 的安全认证。

## 主要功能

- 从 Finder 双击、拖放、菜单或文件夹打开图片与视频；视频使用系统播放器预览。
- 按图片比例调整窗口；支持适合窗口、实际尺寸、滚轮缩放、拖动或滚轮平移、旋转与全屏。
- 在文件夹内前后翻页、循环浏览、缩略图网格和幻灯片放映；可在设置中选择参与浏览的图片格式。
- 悬停时显示窗口操作，右侧显示可上下拖动的文件信息；支持窗口置顶。
- 复制、打印、在访达中显示、移到废纸篓；可在设置中尝试设为默认图片查看器。
- 通过 Sparkle 检查并安装后续更新。更新文件托管在 GitHub Releases，更新清单由 GitHub Pages 提供。

## 常用快捷键

| 快捷键 | 操作 |
| --- | --- |
| ⌘O / ⇧⌘O | 打开图片或视频 / 打开文件夹 |
| 空格、→、↓ / ←、↑ | 下一项 / 上一项 |
| G、⌘G | 切换缩略图网格 |
| ⌘+、⌘− | 放大 / 缩小（包含数字小键盘） |
| ⌘0 / ⌘1 | 适合窗口 / 实际尺寸 |
| Delete / ⌘Delete | 确认后移到废纸篓 / 直接移到废纸篓 |
| ⌘W | 关闭窗口 |

更多操作可从应用菜单中查看。

## 构建与发布

需要 Xcode 和 [XcodeGen](https://github.com/yonaskolb/XcodeGen)。项目最低部署目标是 macOS 13。运行 xcodegen generate 后，用 Xcode 打开喵图.xcodeproj。双击一键打包.command 可按项目版本规则生成 DMG 与 Sparkle 更新清单。

首次在新 Mac 上发布前，需配置专用 Sparkle EdDSA 签名密钥；**私钥只应保存在发布者钥匙串中，不应提交到仓库**。完整发布顺序见 [更新发布说明](更新发布说明.md)。

当前公开仓库用于发布安装包和更新清单；源码仍以本地工作区为准，尚未完整同步到 GitHub。1.0.25 是首个包含更新器的版本，自动替换安装需要在下一个版本发布后完成跨版本验证。
